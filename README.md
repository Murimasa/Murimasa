### 🚀 Featured Test Automation Projects

#### 🎭 [Playwright UI Automation Framework](https://github.com/Murimasa/playwright-ui-framework)
> Modular end-to-end UI testing framework built with **Python**, **Playwright**, and **Pytest** using the **Page Object Model (POM)** pattern.

* **Target Application:** [SauceDemo](https://www.saucedemo.com/)
* **Test Architecture:** Page Object Model (POM), decoupled browser fixtures, session storage state reuse.
* **Key Features:** Data-driven parameterized testing, full checkout purchase flow, web-first auto-wait assertions, automatic failure screenshot hooks, and execution traces.
* **Reporting & CI/CD:** Integrated Allure reporting published directly via GitHub Actions to GitHub Pages.

#### 🚀 [Restful Booker API Automation Framework](https://github.com/Murimasa/postman-api-automation)
> Headless API regression and data-driven testing framework using **Postman**, **Newman CLI**, and **GitHub Actions**.

* **Target API:** Restful Booker API
* **Test Architecture:** Full CRUD lifecycle entity progression with dynamic state variables (auth tokens, booking IDs).
* **Key Features:** Data-Driven Testing (DDT) via external JSON datasets without cloud vendor limitations, multi-layer payload assertions.
* **Reporting & CI/CD:** Fully autonomous Ubuntu runner pipeline in GitHub Actions generating standalone HTML dashboards (`newman-reporter-htmlextra`) stored as workflow artifacts.
